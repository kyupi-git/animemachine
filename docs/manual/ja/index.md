# はじめに

AnimeMachine は、作品情報、購読、手持ちの動画、プレーヤーへの入口をまとめて扱います。まずは「作品を探す → 1 話ダウンロードする → 再生する」までを一度進め、その後に既存のコレクションや設定を追加します。

![作品一覧：画像、購読、保存状況を確認](../../images/library-overview.ja.png)

## 実行する機器を選ぶ

| 使用する機器 | 最初に読むページ |
| --- | --- |
| Windows PC | [PC に導入](desktop.md#windows) |
| NAS、Docker を導入済みの Linux サーバー | [Linux・Docker に導入](docker.md) |
| macOS・Linux PC | [PC に導入](desktop.md#macos-linux) |
| すでに AnimeMachine の画面を開いている | [初回ログイン](first-use.md) |

PC 版は AnimeMachine を起動し、必要に応じてダウンロード用サービスを接続します。NAS の標準構成は Ani-RSS、qBittorrent、Torrent Collector も起動し、自動で接続します。

## 最初の再生まで

1. 使用する機器に導入し、[ログインと画面の確認](first-use.md)を行います。
2. [作品を 1 本購読](subscribe.md)し、字幕と配信版を選びます。
3. 動画が利用可能になったら[再生](playback.md)します。
4. その後、[まとめて続きを再生](continue-watching.md)したり、[既存のコレクションを接続](collections.md)したりできます。

主な操作例には『世界最強の魔女、始めました』を使用しています。配信されている話数や版は時期によって変わるため、実際の検索結果から選んでください。

## 画面と見比べる

各章は一つの作業に対応し、手順では画面のボタン名を使用しています。画像をクリックすると原寸で確認できます。ページ上部で中文・English・日本語を切り替えられます。

完了している作業は飛ばして構いません。問題がある場合は[困ったときは](troubleshooting.md)、または各章の末尾を参照してください。
