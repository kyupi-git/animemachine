# 5. 再生する

利用できる動画がある作品は、詳細画面で話数とプレーヤーを選んで再生します。プレーヤーは操作中の PC・スマートフォンにインストールし、AnimeMachine は NAS 上で動作していても構いません。

## PC で 1 話再生する

1. 作品詳細の **再生** 欄を開きます。
2. 複数の再生元や DVD・BD 版がある場合は先に選びます。
3. 開始する話数を指定し、**PotPlayer で開く** または **VLC で開く** を押します。
4. ブラウザーが外部アプリの起動を確認したら許可します。

![再生欄：再生元、版、話数、プレーヤーを選択](../../images/work-detail.ja.png)

**確認する状態：** 選んだ話数がプレーヤーで再生されます。複数作品を連続で見る場合は[まとめて続きを再生](continue-watching.md)を使います。

## PotPlayer で再生位置を記録する

1. **再生位置を記録する拡張を導入** から拡張パッケージを取得します。
2. PotPlayer を終了し、同梱の `README.txt` に従って `Extension` フォルダーをインストール先へ統合します。
3. PotPlayer を起動し直し、AnimeMachine から再生します。

拡張を導入すると正確な位置を保存し、次回は停止位置の 5 秒前から再開します。拡張なしでも再生でき、メディアへのアクセスを基に話数を記録します。記録はリスト生成時のアカウントに対応します。

## 毎回ブラウザーの確認が出る

Windows の Edge・Chrome では **許可コマンドをコピー** を押し、`Win + R` で `cmd` を開きます。コマンドを貼り付けて一度実行し、ブラウザーを開き直します。

![プレーヤーの操作：許可コマンドと位置記録用の拡張](../../images/playback.ja.png)

現在の Windows アカウントで、このサイトから PotPlayer と VLC を開くことを許可します。既存の許可は保持されます。自動コピーできない場合は、選択されたコマンド全体を `Ctrl+C` でコピーして `cmd` へ貼り付けます。

## スマートフォン・コピーしたアドレス・M3U

スマートフォンに VLC を導入し、ブラウザーで **VLC で開く** を押します。リストのアドレスをコピーしてネットワークストリームとして開くか、M3U をダウンロードして開く方法も使えます。

いずれも生成時のアカウントとの関連を保持します。ただし通常のメディア要求はアクセスした話数を示すもので、**VLC の要求だけでは正確な停止位置を取得できません**。先読みで次の話がアクセスされる場合は、[視聴記録を修正](continue-watching.md#correct)できます。

リストは生成時点の話数で構成されます。新しい話が追加されたら、AnimeMachine で生成し直してください。
