# 10. 困ったときは

現在の症状から順に確認します。一項目ごとに元の操作を試すと、どの変更が有効だったか分かります。

## ページが開かない {#open-page}

1. PC では起動ウィンドウ、Docker ではコンテナーが実行中か確認します。
2. 起動ログに表示されたアドレスとポートを使用します。
3. スマートフォンでは `localhost` を実行機器の LAN アドレスに置き換えます。
4. ポートが使用中の場合は[導入手順](docker.md)で別のポートを選び、再起動します。

## パスワードが分からない

初回の起動ウィンドウやコンテナーログで確認します。PC 版は `data/state/auth/initial-admin.txt`、標準 Docker 構成もプロジェクト内の同じ場所に初期アカウントを保存します。変更済みの場合はそのアカウントを使用し、別の管理者に管理を依頼できます。

## 作品や画像がまだ出てこない

初回は最近の作品を先に準備し、全作品と残りの画像を補完します。ホームの進捗と **設定 → 診断** を確認します。接続復旧後は再試行されます。過去の作品は全体の資料が揃ってから再検索できます。

## リソースがあるのに取得されない {#download}

1. 版の選択後、購読や計画の確認まで完了したか確認します。
2. **設定 → 接続** で Ani-RSS・qBittorrent を確認します。
3. ダウンローダーでタスクの有無、保存先、接続可能なシーダーを確認します。
4. Torrent の結果が閉じている場合は展開し、グループと版を選択します。

## 保存済みの動画を再生できない

1. **設定 → 接続** でメディアフォルダーを読み取れるか確認します。
2. Docker は NAS のフォルダーをマウントしてから、コンテナーのパスを入力します。
3. 走査完了を待ち、動画がある再生元を選びます。
4. 本編判定や作品・話数の名前を確認し、[既存のコレクション](collections.md)も参照します。

## プレーヤーが開かない・アドレスエラーになる

1. 操作中の機器へプレーヤーを導入し、ブラウザーの外部アプリ起動を許可します。
2. リストのアドレスをプレーヤーへコピーするか、リストをダウンロードします。
3. プレーヤーから届く AnimeMachine のアドレスを使用します。別機器の `localhost` はその機器自身です。
4. 期限切れや新着話がある場合は、リストを作り直します。

Windows の PotPlayer 拡張は正確な位置を記録します。VLC などはアクセスした話数を基にするため、誤判定は[視聴記録](continue-watching.md#correct)で修正できます。

## まとめ再生が空になる

対象シーズンに、購読中で最新話が未完了、かつ動画を再生できる TV 作品があるか確認します。一時停止・未購読・非表示・最新話完了の作品は新しいリストに含めません。

## ログのどこを確認するか

**設定 → ログ** で警告・エラーに絞り、操作した時刻付近を確認します。解決しない場合はバージョン、導入方法、再現手順、関連するエラーを記録します。共有する画像・ログからはパスワード、キー、個人のパスを取り除きます。
