# 开始使用

AnimeMachine 把作品资料、追番订阅、已有收藏和播放器入口放在同一个页面。先完成一次“找到作品 → 下载一集 → 打开播放”，再按需要接入已有收藏和调整设置。

![作品列表：查看封面、订阅与收藏状态](../../images/library-overview.png)

## 选择部署方式

| 现在准备在哪里运行？ | 从这里开始 |
| --- | --- |
| Windows 电脑，先试用或管理电脑上的动画 | [电脑部署](desktop.md#windows) |
| 飞牛、群晖等 NAS，或已安装 Docker 的服务器 | [NAS 联合部署](docker.md) |
| macOS 或 Linux 电脑 | [电脑部署](desktop.md#macos-linux) |
| 已经打开 AnimeMachine 页面 | [首次打开](first-use.md) |

电脑部署先启动 AnimeMachine，再按需要连接下载服务；NAS 默认组合会一起部署 AnimeMachine、Ani-RSS、qBittorrent 和资源采集器，并自动建立连接。

## 按顺序完成第一次使用

1. 按设备完成部署，然后[登录并确认页面就绪](first-use.md)。
2. [订阅一部作品](subscribe.md)，选择需要的字幕和版本。
3. 下载完成后[打开播放器](playback.md)。
4. 之后使用[一键继续观看](continue-watching.md)，或[接入已有收藏](collections.md)。

截图用于演示操作。资源检索结果会随时间变化，按页面实际可用的集数和版本选择即可。

## 如何对照阅读

每章对应一个完整任务，各步沿用页面上的按钮名称。点击截图可查看原图；中文、English、日本語可在右上角切换。

已经完成的章节可以跳过。遇到问题时，从[常见问题](troubleshooting.md)按现象查找；涉及某一步的说明也放在对应章节末尾。
