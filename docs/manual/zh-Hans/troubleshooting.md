# 10. 常见问题

从当前看到的现象开始检查。完成一项后重新尝试原来的操作，避免同时更改多项设置。

## 页面打不开 {#open-page}

1. 电脑部署确认启动窗口仍在运行；Docker 查看 AnimeMachine 容器是否运行。
2. 使用实际启动日志中的地址和端口。
3. 从手机访问时，将 `localhost` 换成运行设备的局域网地址。
4. 端口被其它程序占用时，按[部署说明](docker.md)选择空闲端口并重新启动。

## 不知道登录密码

查看首次启动窗口或容器日志。电脑发布包的初始账户在 `data/state/auth/initial-admin.txt`；Docker 默认组合在项目的 `data/state/auth/initial-admin.txt`。已经自行改过密码时，以修改后的账户为准；可让其它管理员协助管理账户。

## 作品或图片还没有出现

首次启动先准备近期作品，其余作品和图片随后在后台补齐。查看首页进度和 **设置 → 诊断** 中的网络状态；恢复连接后会继续尝试。需要查找历史作品时，可等完整资料准备完成后重新搜索。

## 资源找到但没有下载 {#download}

1. 检查是否已经选择资源并确认订阅或下载计划。
2. 在 **设置 → 连接** 确认 Ani-RSS / qBittorrent 可用。
3. 在下载器查看是否已有任务、目标目录是否可用，以及是否有可连接的做种者。
4. Torrent 结果默认折叠时，展开对应区域再选择字幕组和版本。

## 硬盘有文件，作品却不能播放

1. 在 **设置 → 连接** 核对媒体目录可读。
2. Docker 中先核对 NAS 目录已挂载，再填写对应容器路径。
3. 等待文件清点完成；有多个来源时切换到实际包含媒体的来源。
4. 检查文件是否为正片、文件名是否能识别作品和集数，必要时查看[已有收藏](collections.md)。

## 播放器没有打开或提示地址错误

1. 在当前设备安装播放器，并允许浏览器打开外部应用。
2. 复制播放列表地址，在播放器中打开；也可尝试下载列表。
3. 使用播放器所在设备可以访问的 AnimeMachine 地址，避免从其它设备使用 `localhost`。
4. 列表已过期或作品有新集时，返回页面重新生成。

Windows 安装 PotPlayer 扩展后可以记录精确位置；VLC 等方式根据媒体访问记录集数，误判时按[观看记录](continue-watching.md#correct)纠正。

## 本周列表为空

确认所选季度内有已订阅 TV 动画，并且最新一集仍待看完、已经存在可播放媒体。暂停、未订阅、隐藏及最新集已看完的作品不会进入新列表。

## 日志中哪些内容需要处理

在 **设置 → 日志** 选择警告与错误，结合当前操作查看最近记录。长时间无法恢复时，记录软件版本、部署方式、复现步骤与相关错误；分享截图或日志前移除密码、密钥和个人路径。
