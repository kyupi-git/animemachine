4. 購読とダウンロード ​

『世界最強の魔女、始めました』を例に、配信版を選んで動画を取得します。Ani-RSS の購読は以降の配信も追跡し、Torrent は今回選んだリリースをダウンロードします。

作品を探す ​

  1. ホームの タイトル・別名 で検索するか、新作レーダー を開きます。
  2. レーダーでは対象シーズンを選び、作品名から詳細を開きます。
  3. Ani-RSS の結果を確認し、更新が必要な場合はリソースを検索します。

同期 は Ani-RSS が把握している購読・メディア状態を取得します。検索 は対象シーズンの作品を順番に調べます。バックグラウンドで進み、画面に進捗が表示されます。

Ani-RSS の配信版を選ぶ ​

  1. リリースグループを選びます。
  2. 同じグループに複数の版がある場合は、プルダウンで字幕、配信元、画質を確認します。簡体字・繁体字、Baha などもここで区別します。
  3. 希望のリソースを選び、購読を有効化 を押します。確認画面でグループと版を確認し、もう一度 購読を有効化 を押します。
  4. 購読中 になったら、取得済みの話数を作品の再生欄で確認します。

確認する状態： 購読中と表示され、取得した動画が再生欄に並びます。以降の配信は Ani-RSS が取得し、AnimeMachine に状態が同期されます。

言語や画質の不一致表示は、現在の優先条件によるものです。その版を使用する場合は強制購読を選び、確認画面で不一致の項目を確認できます。

放送前の作品や保存用リリースを追跡する ​

作品詳細の リリース追跡 を開き、配信開始時に購読 を選ぶと、リリース待ち として保存されます。定期検索で条件に合う配信版が見つかると、Ani-RSS の購読を開始します。未接続の間も設定は保持されます。

標準では設定のリリースグループを使用します。さらに限定する場合はそのチェックを外し、グループを展開して、例えば Kirara Fantasia → Baha だけを選びます。既存の Ani-RSS 購読の設定は保持されます。

BDRip などの保存用リリースには アーカイブ向けリリースを追跡 を使います。見つかった時点では通知のみで、確認後にダウンロードを選択できます。新作レーダーの リリース追跡 から、一覧の確認・変更・停止ができます。

Torrent を選ぶ ​

  1. 設定 → 接続 で qBittorrent が利用可能か確認します。
  2. 作品詳細で Torrent を検索 し、検索完了を待ちます。
  3. Torrent の結果を展開し、グループと字幕・画質の版を選びます。
  4. ダウンロード計画を確認 で作品、ファイル、保存先を確認して送信します。
  5. qBittorrent を開き、追加された停止中のタスクを選んでダウンロードを開始します。

ローカル Torrent の計画は停止状態で追加され、タスクを開始すると転送が始まります。放送中の作品はシーズンと話数の連続性を確認します。完結作品や映画もコレクションの補完に利用できます。

数百話に及ぶ連載作品は、各バージョンの直近 24 話が連続してそろっているか確認し、最新から 1 話までの遅れを許容します。一度の検索で全話をそろえる必要はありません。保存用の版では、過去の話を分けて収集できます。

手持ちの Torrent プールを使う ​

設定 → 接続 → Torrent Collector では、作品検索とプールを別々に利用できます。

使い方設定
作品ごとに探す詳細で Torrent を検索。別途 Collector を起動する必要はありません
手持ちの .torrent フォルダーを使うTorrent プールのパス を指定し、プールを定期スキャン を有効にします
プールへ自動収集するCompose で Torrent Collector を導入し、Torrent を自動収集 を有効にします

手持ちのプールだけを使う場合は、自動収集を無効にし、定期スキャンを残せます。どの方法でも同じリリース設定を使い、作品詳細から選択します。ファイル一覧と保存先を確認してからダウンロード計画を送信します。

ダウンロードが始まらない ​

AnimeMachine の接続とタスク状態を確認し、qBittorrent でタスクや接続可能なシーダーを確認します。送信済みでピアを待っている状態と、まだ計画を送信していない状態を区別します。確認手順も参照してください。
