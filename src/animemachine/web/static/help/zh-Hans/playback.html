5. 开始播放 ​

作品已有可访问的媒体后，在详情中选择集数和播放器即可开始观看。播放器安装在正在操作的电脑或手机上；AnimeMachine 可以运行在 NAS 上。

在电脑播放一集 ​

  1. 打开作品详情，找到播放区。
  2. 有多个媒体来源或 DVD / BD 版本时，先选择来源与版本。
  3. 选择开始集数，点击 使用 PotPlayer 打开 或 使用 VLC 打开。
  4. 浏览器首次询问是否打开外部应用时，选择打开。

完成标志： 播放器打开并开始播放选中的集数。需要连续播放多个作品时，使用一键继续观看。

PotPlayer 记忆精确位置 ​

  1. 点击 安装扩展以记忆播放进度，下载扩展包。
  2. 退出 PotPlayer，按包内 README.txt 将 Extension 目录合并到 PotPlayer 安装目录。
  3. 重新打开 PotPlayer，再从 AnimeMachine 开始播放。

安装扩展后，AnimeMachine 可以记录精确位置，下次从停止位置前 5 秒续播。未安装扩展时仍可播放，按媒体访问记录集数；正在查看的作品与账户以这次生成的播放列表为准。

浏览器反复询问打开播放器 ​

Windows 的 Edge / Chrome 可点击 复制授权命令，按 Win + R，输入 cmd 并回车，粘贴命令运行一次，再重新打开浏览器。

命令为当前 Windows 账户允许本站调用 PotPlayer 和 VLC，保留已有授权。若自动复制受阻，会显示已选中的完整命令；按 Ctrl+C 复制，再到 cmd 中运行。

手机、复制地址与下载播放列表 ​

手机先安装 VLC，再从手机浏览器点击 使用 VLC 打开。也可以复制播放列表地址，在播放器中选择“打开网络串流”；或者下载 M3U 文件后打开。

这些方式都会保留生成列表时的账户关联，但媒体请求只能作为开始观看的线索。VLC 无法仅靠普通媒体请求精确回传停止时间；预读取也可能提前访问下一集，需要时手动纠正记录。

复制的列表由生成时的集数组成。以后出现新集时，回到 AnimeMachine 重新生成列表即可。
