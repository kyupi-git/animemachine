            AnimeMachine 是一款全自动动画收藏库系统，负责把动画元数据、Torrent 池、媒体目录和外部只读媒体库整理到同一套本地 Catalog 与状态体系。

            程序连续完成资源筛选、下载投料、多级目录规划、系列关系整理、收藏核验、Web 浏览与长期贮存；qBittorrent、Ani-RSS 与 Torrent Collector 均为可选组件。

            作品关系图根据 Bangumi Archive 及辅助证据组织前作、续作、总集篇、番外、衍生、不同演绎和跨系列关联，并在可接受的计算时间内优化节点布局与关系线轨道。

            AnimeMachine 本身不提供动画检索或下载，也不内置 Torrent、磁力链接或媒体内容。外部媒体目录按只读来源处理；实际下载与订阅由用户连接的外部组件完成。

            版本 —

            github.com/kyupi-git/animemachine

            • Bangumi Archive提供本地动画元数据底包与作品关系基础。
            • Bangumi API用于补全底包中缺失或明显异常的公开元数据。
            • MyAnimeList在本地证据不足时作为作品身份和前后作关系的辅助来源。
            • ani-rss提供可选的新番订阅、状态同步与远程播放能力；AnimeMachine 通过其 HTTP API 连接。
            • ASSRT是用户可选的外部字幕 API；字幕版权及使用条件由对应服务说明。
            • OpenSubtitles是用户可选的外部字幕 API；字幕版权及使用条件由对应服务说明。
